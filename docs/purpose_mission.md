# Purpose and Mission

The **Trading Knowledge Base** serves as an aggregate collection of algorithms, predictive modeling pipelines, and execution engines designed for scalable systematic trading.

- `matsaya`: Maintain cleanly-architected, test-driven standalone strategies.
- `sandwich`: Generate predictive intelligence pipelines driven by Machine Learning (DuckDB + Scikit-Learn models).
- `new_system`: Act as a fast orchestrator executing market orders efficiently over Shoonya API integrations.

- Above VWAP = bullish bias (institutions accumulating)
- Below VWAP = bearish bias (institutions distributing)
- VWAP crossovers are high-probability trend signals

**Without VWAP, we're flying blind on 50% of institutional order flow analysis.**

| Option | Effort | Accuracy | Timeline |

### Recommended Immediate Fix

Replace `buf.append(spot, spot, spot, spot)` with actual volume or a proxy:

```python
# Option A: TWAP (price-only approximation)
class TWAPBuffer:
    def __init__(self, period=20):
        self.prices = []  # deque with maxlen=period
    def append(self, price):
        self.prices.append(price)
    def value(self):
        return sum(self.prices) / len(self.prices) if self.prices else 0
```
